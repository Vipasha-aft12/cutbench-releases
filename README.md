# Cutbench releases

Installers for the Cutbench desktop app. This repository holds **only** the
finished installers (attached to each release) and the small `latest*.yml`
files the app reads to find updates. The source code lives elsewhere.

Download the newest version from **[Releases](../../releases/latest)**:

- **Mac:** `Cutbench-<version>-mac.dmg` (Apple Silicon and Intel)
- **Windows:** `Cutbench-Setup-<version>.exe` (64-bit Windows 10 or 11)
